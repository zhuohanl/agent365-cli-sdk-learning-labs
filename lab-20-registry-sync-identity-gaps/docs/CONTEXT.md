# Lab 20 domain language

## Agent population

All third-party agents in a customer's environment that are eligible for the
governance solution. The population is not limited to agents selected for a
particular rollout, demonstration, or implementation cohort.

## Demonstration cohort

A deliberately selected subset of the agent population used to demonstrate
and validate the solution. A demonstration cohort does not define the
solution's applicability or identity namespace.

## Committed fleet

A delivery and tracking cohort used by the implementation project. It is not
the customer-wide governed agent population and must not be encoded as the
owner or scope of a durable agent identity.

## Companion registration

A separately managed Agent Registration associated with a third-party agent
observed through Registry Sync. It remains distinct from the Registry Sync
inventory record.

## Agent governance

The customer-wide capability that associates identity and governance records
with eligible agents. This is the canonical domain term for the companion
identity namespace.
